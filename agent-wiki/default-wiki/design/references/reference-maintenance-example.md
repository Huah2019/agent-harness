# 引用资料维护清单（示例）

本文件展示普通引用文档的组织方式，不代表真实业务资产。
维护引用资料时，由 [核心设计](../core-design.md) 引导到这里；本文件不独立注册为知识。

| 检查项 | 应达到的状态 |
| --- | --- |
| 读取入口 | 引用方说明何时读、读来做什么 |
| 唯一来源 | 详细资料只维护一份，多个知识可共享链接 |
| 状态说明 | 待验证、已验证和已废弃明确区分 |
| 文件变动 | 移动检查链接；有引用时不直接删除 |
| 收尾检查 | CLI check 通过，无意外的上下文注册 |

清单按实际用途更新即可，不添加知识 frontmatter，也不调用 use。
